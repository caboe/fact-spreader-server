Built for the misleading half-truth

A claim can be literally accurate and still create a false impression. Fact Spreader separates the two questions: is the factual core supported, and does the framing leave out something that changes the conclusion?

  • The gate runs in code. A model proposes; deterministic rules over the evidence decide. No free-text verdicts.
  • Missing context is part of the verdict. Topic-specific confounder checks trigger targeted re-retrieval before a clean true is allowed.
  • Citations are checked. An evidence identifier that is not in the retrieved set is rejected, not shown.
  • Only approved documents count. Claim text, queries and uploads never enter the corpus.

Seven verdicts, one deterministic rule

The overall verdict is computed from the statement verdicts. A true sentence in a misleading frame can still end as true_but_misleading.

True True but misleading Partially false False Contested Insufficient evidence Not checkable

How the verdict is computed

How a check runs

  1. Moderate the input. Most findings flag the check; sexual content involving minors is always blocked.
  2. Extract statements. Each statement keeps its span, its kind and a checkworthiness judgement.
  3. Retrieve evidence. Hybrid graph and vector search over approved documents only.
  4. Verify and audit. Stances and proposed verdicts are structured output; confounder checks trigger targeted re-retrieval.
  5. Gate and decide. Source count, independence, publisher grade and missing-context support are checked in code.
  6. Stream the report. The substance arrives first; a consistency-checked narrative follows.

Run it on your own instance

The stack is self-hosted: Postgres with pgvector, Redis, a FastAPI backend, stock LightRAG and a Caddy edge. You need Docker and an approved provider key. 

cp .env.example .env
make install
make stack-up

Open https://localhost:8443 and complete the setup wizard with SETUP_TOKEN from .env. Operating details are in the repository.
