# Methodology data

Content, not code: the shipped publisher grades (`publishers.json`, criteria in
[`docs/SOURCE_GRADING.md`](../docs/SOURCE_GRADING.md)), the confounder checklists per topic
(`checklists/`) and the argument-pattern taxonomy (`patterns.json`). They change what the
pipeline concludes, so edits belong to the methodology role and are versioned.
